creative 仿写：课堂没讲，AI 教你第 7 种 effect · 官方示例 257 · 电影片墙

课堂只讲了 6 种 effect。我照着官方示例 swiper/demo/257-effect-creative.html 配合 AI 读懂了 creativeEffect 的 transform 写法，为演示新增第 7 个按钮「creative 电影片墙」： 上一张缩小左移带角度、下一张放大右移带角度，像电影选片墙一样层叠排开。

与 AI 的关键往返（任务二）

🧑‍💻 我（马昕玉子）的提示词

我在官方示例 swiper/demo/257-effect-creative.html 里看到 creativeEffect 里写了 prev: { translate: ["-125%", 0, -120], rotate: [0,0,-10] } 这样的对象。请用大白话讲： translate / rotate / origin 三个键各控制什么？translate 数组里的三个值分别对应什么方向？百分数是相对谁的？

🤖 AI 的解释（我用自己的话复述）

creativeEffect 给每一张 slide 单独定义"离开时变成 prev 的样子、进来时从 next 的样子恢复"：
① translate: [x, y, z]——x 正值往右、负值往左；y 正值往下；z 是 3D 远近（负值=远离屏幕，看起来变小）。 百分数相对 slide 自身的宽/高："-125%" 就是把自己整个身位再往左挪 1.25 个身位。
② rotate: [x, y, z]——绕三条轴转的角度（度），z 轴就是平面上的歪斜。
③ origin——变换的"轴心点"，默认在 slide 中心，改成 "left top" 就绕左上角转。

🧑‍💻 追问（实现前后都追问过）

那帮我生成一份配置：prev 缩小左移带角度，next 放大右移带角度，要像电影选片墙。另外把 z 轴角度改成 20 度会是什么效果？直接给完整 creativeEffect。

🤖 AI 给出的配置（已亲自粘贴验证 ✓，就是下面按钮背后的代码）

creativeEffect: {
  limitProgress: 2,            // 相邻各 2 张也参与变形，片墙更有层次
  prev: {                      // 上一张：缩小 + 左移 + 逆时针歪
    translate: ['-118%', '-4%', -160],
    rotate: [0, 0, -14],
    opacity: .55, scale: .82
  },
  next: {                      // 下一张：放大 + 右移 + 顺时针歪
    translate: ['118%', '4%', -160],
    rotate: [0, 0, 14],
    opacity: .9, scale: 1.06
  }
}

综合创作 + 技术答辩：超纲加分项第六件展品「爱达·魔都号」+ keyboard / mousewheel / zoom / parallax

两件事都做了：① 用 AI 生成了第六件展品「爱达·魔都号」的首图（首艘国产大型邮轮，2024 年 1 月首航，横版 16:9，见下方 slide，已标注 AI 生成）；② 课堂没讲过的超纲能力四选一（可多用）——我把 keyboard 键盘、mousewheel 滚轮、zoom 双击缩放、parallax 视差四种全加齐了。

与 AI 的关键往返（任务三）

🧑‍💻 我（马昕玉子）的提示词

给轮播加三个课堂上没讲的能力：① 键盘左右方向键翻页，但只在轮播可见时生效，别影响页面滚动； ② 鼠标滚轮翻页——但我担心它会劫持整页滚动，帮我处理这个矛盾；③ 标题和副标题想有视差效果（图片动得慢、文字动得快）。 给完整参数和 HTML 写法。

🤖 AI 第 1 轮回答

keyboard: { enabled: true },
mousewheel: { enabled: true },
parallax: true
（HTML 里加 data-swiper-parallax 属性）
验证发现 AI 第一轮不对：① keyboard 没加 onlyInViewport:true → 页面任意位置按方向键都会抢走翻页； ② mousewheel 没处理整页滚动矛盾 → 滚轮一进轮播区域页面就没法往下滚了； ③ parallax 只开了开关，slide 里没写 data 属性 → 视差根本不动。

🧑‍💻 追问修正

三处都改：keyboard 加 onlyInViewport；mousewheel 加 forceToAxis: true（触控板横滑才翻页，竖滑留给页面滚动），再加 releaseOnEdges 让页面边缘把滚轮还给文档；视差请给出每个元素该写什么 data 属性、数值代表什么。

🤖 AI 第 2 轮回答（已验证 ✓，即下方演示台的配置）

keyboard: { enabled: true, onlyInViewport: true },
mousewheel: { forceToAxis: true, releaseOnEdges: true, sensitivity: 1 },
parallax: true
<!-- slide 内部：数值是"该元素相对 slide 宽度最多位移多少" -->
<h3 data-swiper-parallax="-220">标题：横移 220px</h3>
<p  data-swiper-parallax="-120">副标题：横移 120px，比标题慢</p>

🧑‍💻 追问：zoom 双击缩放（四选一里最后一个还没实现的）

还想加 zoom 双击缩放，和键盘/滚轮/视差一起用会不会打架？完整写法是什么？

🤖 AI 第 3 轮回答

zoom: true
<!-- 但只写这一行是无效的！-->
验证发现 AI 第 3 轮不对：只加 zoom:true 双击图片毫无反应——zoom 还要求把图片包进 swiper-zoom-container 容器里才生效。追问后 AI 补全了写法（见下），已验证 ✓。

🤖 AI 第 4 轮回答（已验证 ✓，即下方演示台的配置）

zoom: { maxRatio: 3, minRatio: 1 }
<!-- slide 结构必须改为：-->
<div class="swiper-slide">
  <div class="swiper-zoom-container"><img src="…"></div>
  <div class="mxyz_cap">…</div>
</div>
双击图片放大至最大 3 倍，再双击还原；移动端双指捏合也能缩放。
